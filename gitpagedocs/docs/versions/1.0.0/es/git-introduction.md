# Fundamentos tecnicos

Fundamentos tecnicos usados en este repositorio.

## Fundamentos de backend

- Arquitectura modular NestJS
- Modelo de datos Prisma + PostgreSQL
- JWT con RBAC
- Capa de extraccion IA por provider

## Fundamentos de frontend

- Estructura Next.js App Router
- Sesion por cookies HTTP-only
- Estrategia de estado con Redux Toolkit + React Query

## Fundamentos de infraestructura

- Docker Compose para paridad local
- LocalStack para emulacion S3
- Configuracion orientada por entorno

## Fundamentos operativos

- Healthcheck para readiness
- Respuestas API estandarizadas
- Auditoria para acciones sensibles
