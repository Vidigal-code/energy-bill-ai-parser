# Stack Tecnológico

Descubre las herramientas y lenguajes empleados para este proyecto de primer nivel:

## Frontend
- **React (v18) + Next.js (App Router):** Aplicaciones rápidas y reactivas con renderización del lado del servidor de base.
- **Redux Toolkit & React Query:** Control de ciclos de vida globales, peticiones en caché, e interacciones.
- **Tailwind CSS + Lucide React:** Utilidades CSS potentes y livianas listas para diseño adaptable, con un juego de iconos elegante.
- **Axios:** Cliente confiable para llamadas seguras en formato HTTP-only de cookies validables en NestJS.

## Backend
- **Node.js + NestJS:** Framework corporativo superior que gestiona Módulos, Servicios e Inyección de Dependencias impulsado 100% en TypeScript.
- **Prisma ORM:** Manejador SQL intuitivo de tipado rígido garantizado.
- **Node-Jose (JWE):** Seguridad militar al garantizar que cada archivo sea un Payload oculto inyectado en una cadena indescifrable ante fugas.

## Persistencia e Integración
- **PostgreSQL:** El pilar central de transacciones para almacenamiento duradero.
- **LocalStack / AWS S3 SDK:** Ambiente en contenedores locales emulando Amazon puro para lograr ambientes predecibles sin necesidad inicial de costosas facturas AWS.
- **Inteligencia Artificial (Gemini y Ollama):** Nexos nativos para comunicar y consumir la inteligencia generativa que escanea las facturas.

## Entorno y Certificación
- **Docker y Docker Compose:** Un ecosistema hermético; tu API, el sitio web, las bases de datos y la IA, todos conviviendo en contenedores con su propia abstracción de red.
- **ESLint, Prettier, Jest, Supertest:** Las defensas necesarias para verificar de punta a punta la sanidad del código antes del despliegue en producción.
