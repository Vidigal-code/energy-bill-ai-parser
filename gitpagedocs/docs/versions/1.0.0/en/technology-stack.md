# Technology Stack

Explore the robust, modern tooling driving this application:

## Frontend
- **React (v18) + Next.js (App Router):** Fast, React-based web applications with built-in server-side paradigms.
- **Redux Toolkit & React Query:** Total control over global state, request caching, and complex UI mutations.
- **Tailwind CSS + Lucide React:** Utility-first CSS framework coupled with scalable SVG UI icons.
- **Axios:** Ensures robust HTTP-only cookie delivery directly into Backend API validators.

## Backend
- **Node.js + NestJS:** Main framework offering high-grade abstractions via DI, Controllers, Pipes, and Guards running on strictly-typed TypeScript.
- **Prisma ORM:** The modern and intuitive SQL tool for schema migrations and compile-time typings.
- **Node-Jose (JWE):** Guaranteeing payload protection by strictly hashing and enciphering standard outputs via robust Web Encryption algorithms.

## Persistence and Integrations
- **PostgreSQL:** Trusted, reliable, core relational transactional database tracking robust financial metrics.
- **LocalStack / AWS S3 SDK:** Offline, developer-friendly simulation of the exact AWS S3 pipeline matching production standards.
- **Artificial Intelligence (Gemini & Ollama):** Bridging standard app logic to cutting-edge Language Models to execute Vision and NLP requests instantly.

## Environment & Logistics
- **Docker and Docker Compose:** Everything perfectly containerized. Frontend, Backend, Relational DB, and Offline AWS mimicking all bundled inside their own network.
- **ESLint, Prettier, Jest, Supertest:** Full testing suites ranging from static code analysis to unit and Integration e2e endpoints validation.
